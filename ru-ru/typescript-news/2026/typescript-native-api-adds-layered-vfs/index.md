# Нативный API TypeScript добавляет многоуровневые виртуальные файловые системы


**Опубликовано:** 9 сентября 2026 г.

Нативный API TypeScript теперь может создавать и обновлять snapshot с явно заданными данными виртуальной файловой системы. Инструменты могут моделировать добавление, изменение и удаление файлов без повторного построения всего ввода файловой системы.

## Что изменилось

Новые вспомогательные функции `createFileSystem`, `createFileSystemWithLib` и `createFileSystemLayer` создают объекты VFS, которые принимают API snapshot. `Snapshot.update` может накладывать новый слой кэша поверх существующего snapshot.

VFS типа `full` полностью находится в памяти и не обращается к callback файловой системы host или session. VFS типа `layer` обращается к host при промахе кэша и может использовать `removedPaths`, чтобы скрывать файлы или каталоги, существующие на host. Оба варианта поддерживают символические ссылки внутри виртуальной файловой системы и на пути host.

## Текущее ограничение

Snapshot на основе VFS по-прежнему считаются реальными snapshot, поэтому нативный API сохраняет ограничение на один реальный snapshot одновременно. Пока операции со snapshot остаются последовательными.
