# Нативный компилятор TypeScript получил экспериментальную поддержку WebAssembly


**Опубликовано:** 2026-10-29

29 октября 2026 года Microsoft объединила экспериментальную поддержку `wasip1/wasm` с нативным компилятором TypeScript. Изменение позволяет запускать компилятор в средах WASI и предоставляет транспорт JavaScript API, пригодный для браузера.

## Что изменилось

* Один и тот же `tsc.wasm` может работать как команда WASI для CLI или языкового сервера либо как reactor для синхронных и асинхронных вызовов JavaScript API.
* Новый пакет артефактов `@typescript/typescript-wasip1-wasm` содержит компилятор WebAssembly и файлы библиотек. Хост `typescript/wasm` предоставляет `instantiateWasm` и `instantiateWasmSync`; оба пакета должны иметь строго одинаковую версию.
* Расширение VS Code for Web получает точку входа, запускающую `tsc.wasm --lsp`. Изменение включает тесты API в Node.js и базовые браузерные тесты в Chromium.

## Доступность

Это объединённое экспериментальное изменение, а не анонс стабильного выпуска WebAssembly. Бинарный файл, структура пакета и хост `typescript/wasm` могут измениться без предупреждения.
