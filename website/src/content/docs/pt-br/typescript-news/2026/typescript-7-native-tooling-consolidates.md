**Publicado:** 27 de julho de 2026

Os mantenedores do TypeScript esclareceram como as ferramentas nativas do TypeScript 7 serão consolidadas após o lançamento estável.

## O que mudou

Ryan Cavanaugh confirmou que o nome `tsgo` está efetivamente deixando de ser usado. O código nativo deve voltar ao repositório principal `microsoft/TypeScript`, permitindo que o projeto volte a ter um único backlog de issues.

Jake Bailey também esclareceu que a extensão nativa do VS Code não deve ser descontinuada. Em vez disso, ela deve ser incorporada em breve, de forma semelhante à extensão do depurador JavaScript.

Para quem desenvolve com TypeScript, isso significa que os nomes e o repositório separados usados durante a prévia são partes transitórias da migração para o TypeScript 7, e não a estrutura de longo prazo pretendida para o projeto.
