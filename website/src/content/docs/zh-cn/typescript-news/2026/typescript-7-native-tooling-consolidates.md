**发布日期：** 2026 年 7 月 27 日

TypeScript 维护者澄清了稳定版发布后 TypeScript 7 原生工具将如何整合。

## 主要变化

Ryan Cavanaugh 确认，`tsgo` 这一名称实际上将不再使用。原生代码库预计会迁回主 `microsoft/TypeScript` 仓库，使项目重新使用统一的 issue 列表。

Jake Bailey 还澄清，原生 VS Code 扩展并没有弃用计划。相反，它预计将在近期被内置，方式类似 JavaScript 调试器扩展。

对开发者而言，这意味着独立的预览名称和仓库只是 TypeScript 7 迁移过程中的过渡安排，而不是长期的项目结构。
