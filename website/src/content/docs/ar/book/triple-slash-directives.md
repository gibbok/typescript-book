توجيهات الشرطات المائلة الثلاث هي تعليقات خاصة تقدّم إلى المصرّف تعليمات حول كيفية معالجة ملف. تبدأ هذه التوجيهات بثلاث شرطات مائلة متتالية (`///`)، وتوضع عادةً في أعلى ملف TypeScript، ولا تؤثر في السلوك وقت التشغيل.

تُستخدم توجيهات الشرطات المائلة الثلاث للإشارة إلى التبعيات الخارجية، وتحديد سلوك تحميل الوحدات، وتمكين بعض ميزات المصرّف أو تعطيلها، وغير ذلك. فيما يلي بعض الأمثلة:

الإشارة إلى ملف تصريح:

<!-- skip -->
```typescript
/// <reference path="path/to/declaration/file.d.ts" />
```

تحديد تنسيق الوحدة:

<!-- skip -->
```typescript
/// <amd|commonjs|system|umd|es6|es2015|none>
```

تمكين خيارات المصرّف، وفي المثال التالي الوضع الصارم:

<!-- skip -->
```typescript
/// <strict|noImplicitAny|noUnusedLocals|noUnusedParameters>
```
