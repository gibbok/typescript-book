В TypeScript объектные типы описывают форму объекта. Они определяют имена и типы свойств объекта, а также указывают, являются ли эти свойства обязательными или необязательными.

В TypeScript объектные типы можно определить двумя основными способами:

Интерфейс определяет форму объекта, задавая имена, типы и необязательность его свойств.

```typescript
interface User {
    name: string;
    age: number;
    email?: string;
}
```

Псевдоним типа, подобно интерфейсу, определяет форму объекта. Однако он также может создавать новый пользовательский тип на основе существующего типа или сочетания существующих типов. Это включает определение типов-объединений, типов-пересечений и других сложных типов.

```typescript
type Point = {
    x: number;
    y: number;
};
```

Тип также можно определить анонимно:

```typescript
const sum = (x: { a: number; b: number }) => x.a + x.b;
console.log(sum({ a: 5, b: 1 }));
```
