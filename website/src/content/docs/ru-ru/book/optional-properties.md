В объекте свойство можно сделать необязательным, добавив вопросительный знак `?` в конец его имени:

```typescript
type X = {
    a: number;
    b?: number; // Optional
};
```

Для необязательного свойства можно указать значение по умолчанию:

```typescript
type X = {
    a: number;
    b?: number;
};
const x = ({ a, b = 100 }: X) => a + b;
```
