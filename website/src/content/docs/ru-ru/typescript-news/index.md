Следите за важными выпусками и обновлениями проекта TypeScript с помощью кратких обзоров, основанных на официальных источниках TypeScript.

## Последние новости

### [TypeScript 7.1 добавляет import attributes в ambient-модули](./2026/typescript-7-1-import-attributes-ambient-modules/)

**Опубликовано:** 1 сентября 2026 г.

Шаблонные ambient-модули теперь могут объявлять типы import attributes, позволяя TypeScript выбирать типы по атрибутам import.

### [TypeScript 7 исправляет учёт доступности сеттеров в объединениях и пересечениях](./2026/typescript-7-fixes-setter-accessibility/)

**Опубликовано:** 24 августа 2026 г.

Нативный модуль проверки типов теперь учитывает доступность сеттера отдельно от доступности геттера для свойств в объединениях и пересечениях.

### [TypeScript 7 добавляет область поиска символов в рабочем пространстве](./2026/typescript-7-workspace-symbol-search-scope/)

**Опубликовано:** 7 августа 2026 г.

В нативной языковой службе появилась настройка, позволяющая ограничить поиск символов в рабочем пространстве текущим проектом вместо всех открытых проектов.

### [TypeScript 7 оптимизирует потребление памяти в Go to Implementation](./2026/typescript-7-go-to-implementation-memory-fix/)

**Опубликовано:** 30 июля 2026 г.

Нативная языковая служба теперь избегает квадратичного роста потребления памяти при поиске большого количества реализаций в крупных проектах с глубоко вложенными типами.

### [TypeScript 7 обновляет диагностику конфигурации после изменения файлов](./2026/typescript-7-refreshes-config-diagnostics/)

**Опубликовано:** 30 июля 2026 г.

Нативная языковая служба теперь повторно публикует ошибки `tsconfig.json` и `jsconfig.json` после изменения отслеживаемых файлов конфигурации.

### [Нативные инструменты TypeScript 7 консолидируются](./2026/typescript-7-native-tooling-consolidates/)

**Опубликовано:** 27 июля 2026 г.

Сопровождающие проекта пояснили, что название `tsgo` больше не будет использоваться, нативная кодовая база вернётся в основной репозиторий TypeScript, а нативное расширение VS Code будет поставляться в комплекте.

### [В нативном API TypeScript 7 появились методы emit](./2026/typescript-7-native-api-adds-emit-methods/)

**Опубликовано:** 24 июля 2026 г.

В нативный API TypeScript добавлены методы emit для генерации выходных данных всей программы в файловую систему или память, а также выбранных выходных данных JavaScript или деклараций в память.

### [TypeScript 7.0 уже доступен](./2026/typescript-7-released/)

**Опубликовано:** 8 июля 2026 г.

TypeScript 7 представляет новый компилятор и новую языковую службу на основе Go, которые значительно ускоряют сборку и операции в редакторе.

### [Объявлен релиз-кандидат TypeScript 7.0](./2026/typescript-7-release-candidate/)

**Опубликовано:** 18 июня 2026 г.

Команда TypeScript выпустила финальную предварительную версию TypeScript 7 с параллельной проверкой типов, сборкой проектов и расширенной поддержкой редакторов.
