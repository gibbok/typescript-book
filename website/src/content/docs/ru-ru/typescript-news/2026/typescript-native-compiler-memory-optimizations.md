**Опубликовано:** 14 октября 2026 г.

Microsoft объединила несколько оптимизаций памяти в нативном компиляторе TypeScript. Они сокращают память, удерживаемую внутренними структурами проверки типов, не меняя синтаксис TypeScript.

## Что изменилось

* Блоки типизированных арен теперь рассчитаны примерно на 512 байт вместо фиксированных 256 объектов. В тесте VS Code для этого изменения удерживаемая память кучи сократилась на 8.54%, объём сканирования сборщиком мусора — на 10.44%, а число событий выделения памяти выросло на 13.91%.
* Необязательные сигнатуры, сведения об индексах и кеши построителя узлов вынесены из записей `StructuredType`, размер которых уменьшился со 144 до 88 байт.
* Разрешённые узлы типов и сигнатуры используют постраничные хранилища связей узлов при наличии стабильных ID; для остальных ID сохраняется резервная карта.

## Доступность

Изменения объединены 14 октября 2026 г. В исходных pull request не указана стабильная версия npm, содержащая их. Результаты тестов относятся только к измеренному изменению и нагрузке.
