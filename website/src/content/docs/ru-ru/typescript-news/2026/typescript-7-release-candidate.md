**Опубликовано:** 18 июня 2026 г.

Microsoft выпустила релиз-кандидат TypeScript 7.0 — последнюю предварительную версию перед стабильным выпуском TypeScript 7.

## Что изменилось

В релиз-кандидате TypeScript перешёл на новый компилятор и новую языковую службу на основе Go. Логика проверки типов была перенесена из TypeScript 6, чтобы сохранить существующую семантику и одновременно повысить производительность благодаря нативному коду и параллелизму с общей памятью.

В TypeScript 7 появились параллельная проверка типов и сборка проектов со ссылками. Параметр `--checkers` управляет количеством обработчиков проверки типов, а `--builders` — количеством обработчиков сборки проектов со ссылками.

На момент объявления релиз-кандидат можно было установить из npm:

```shell
npm install --save-dev typescript@rc
```

## Совместимость

Релиз-кандидат не включал стабильный программный API. Команда TypeScript предоставила пакет совместимости `@typescript/typescript6`, чтобы инструменты, которым требуется API TypeScript 6, могли работать вместе с новым компилятором.

В релиз-кандидате также были приняты настройки по умолчанию TypeScript 6, а использование параметров, объявленных устаревшими в TypeScript 6, приводило к ошибке. Командам рекомендовалось сначала перейти на TypeScript 6 и только затем оценивать TypeScript 7.
