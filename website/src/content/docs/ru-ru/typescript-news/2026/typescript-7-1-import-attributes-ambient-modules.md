**Опубликовано:** 1 сентября 2026 г.

Нативный компилятор TypeScript теперь поддерживает типы import attributes в шаблонных объявлениях ambient-модулей. Благодаря этому объявления могут различать import по атрибутам вроде `type: 'css'` или `type: 'text'`.

## Что изменилось

Если import содержит атрибуты, TypeScript может разрешить его через подходящий шаблонный ambient-модуль. Сопоставление использует assignability; если подходят несколько объявлений, TypeScript выбирает объявление с наиболее конкретным типом атрибутов.

Пока типы атрибутов в таких объявлениях ограничены обычными свойствами, значения которых имеют строковые литеральные типы. Объявления с одинаковым шаблоном и идентичными типами атрибутов могут объединяться; разные типы остаются раздельными.

## Совместимость

Изменение объединено для этапа TypeScript 7.1.0 Beta. Оно не добавляет встроенные объявления CSS- или текстовых import в стандартную библиотеку, поэтому проекты и инструменты по-прежнему должны определять нужные ambient-модули.
