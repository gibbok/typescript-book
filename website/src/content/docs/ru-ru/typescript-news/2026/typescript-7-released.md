**Опубликовано:** 8 июля 2026 г.

Microsoft выпустила TypeScript 7.0 — первую стабильную версию, созданную на новой нативной кодовой базе проекта на Go.

## Что изменилось

TypeScript 7 использует нативный код, многопоточность с общей памятью и дополнительные оптимизации. Согласно опубликованным командой TypeScript результатам тестов производительности, полная сборка стала в 7.7–11.9 раза быстрее, чем в TypeScript 6.

В этом выпуске языковая служба также перешла на Language Server Protocol. Поддерживаемые редакторы могут использовать ту же нативную основу для ускорения загрузки проектов, диагностики, автодополнения и навигации.

Установите стабильный выпуск из npm:

```shell
npm install --save-dev typescript
```

## Совместимость

TypeScript 7.0 не предоставляет стабильный программный API. Инструментам, которые встраивают TypeScript, включая актуальные версии Astro, Vue, MDX и Svelte, а также некоторые рабочие процессы Angular, до появления нового API всё ещё может требоваться TypeScript 6.

По ожиданиям команды TypeScript, новый API появится в TypeScript 7.1. Перед обновлением следует проверить поддержку новой версии используемыми в проекте фреймворками и инструментами.
