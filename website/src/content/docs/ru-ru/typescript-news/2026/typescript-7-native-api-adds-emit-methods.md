**Опубликовано:** 24 июля 2026 г.

В нативную кодовую базу TypeScript добавлены программные интерфейсы генерации выходных данных для инструментов, которым требуется создавать JavaScript или декларации.

## Что изменилось

Добавленный API предоставляет четыре способа генерации выходных данных с различным поведением при выборе файлов и записи результата.

* `program.emit(emitOnly?: EmitOnly)` генерирует выходные данные всей программы в файловую систему, включая настроенную виртуальную файловую систему, и учитывает параметры блокировки генерации, такие как `noEmit` и `noEmitOnError`.
* `program.emitToString(emitOnly?: EmitOnly)` генерирует выходные данные всей программы в виде строковых результатов в памяти и также учитывает параметры блокировки генерации.
* `program.getJavaScriptEmit(files?: readonly DocumentIdentifier[])` возвращает выходные данные JavaScript для выбранных файлов в памяти, обходя параметры блокировки генерации.
* `program.getDeclarationEmit(files?: readonly DocumentIdentifier[])` аналогичным образом предоставляет выходные файлы деклараций для выбранных файлов.

Таким образом, пользователи API могут отдельно выбирать обычную генерацию выходных данных всей программы и целевую генерацию в памяти.

## Доступность

Изменение было внесено в нативную кодовую базу TypeScript 24 июля 2026 г. В источнике не указана стабильная версия npm, содержащая эти API, поэтому инструментам следует проверить их поддержку в используемой версии TypeScript.
