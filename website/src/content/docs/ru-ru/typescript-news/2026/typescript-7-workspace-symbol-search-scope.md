**Опубликовано:** 7 августа 2026 г.

Microsoft добавила область поиска символов в рабочем пространстве для нативной языковой службы TypeScript.

## Что изменилось

Новая настройка `workspaceSymbols.scope` имеет два значения. `allOpenProjects` используется по умолчанию и выполняет поиск символов во всех открытых проектах. `currentProject` ограничивает поиск проектами, содержащими переданный документ.

Теперь нативное расширение VS Code добавляет поддерживаемый документ TypeScript или JavaScript в запросы `workspace/symbol`. Оно отдаёт приоритет активному документу, а при его отсутствии использует открытый поддерживаемый документ. Языковая служба использует этот документ, только если значение `workspaceSymbols.scope` равно `currentProject`; в противном случае поиск по всем открытым проектам сохраняется.

## Почему это важно

В рабочем пространстве с несколькими проектами, содержащими символы с похожими именами, `currentProject` может ограничить набор результатов соответствующим проектом. Значение по умолчанию сохраняет прежнее поведение, поэтому эту возможность необходимо включить явно.

## Доступность

Изменение было внесено в нативную кодовую базу TypeScript после выпуска TypeScript 7.0. В источнике не указана стабильная версия npm, включающая это изменение, поэтому, прежде чем полагаться на эту настройку, проверьте примечания к выпуску установленной версии.
