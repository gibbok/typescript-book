**公開日:** 2026年7月30日

Microsoft は、追跡対象の `tsconfig.json` または `jsconfig.json` ファイルが変更された後に、TypeScript のネイティブ言語サービスで設定ファイルの診断情報を更新する修正をマージしました。

## 変更点

設定ファイルの診断情報は、言語サービスのスナップショット更新時に公開されます。以前は、監視対象の設定ファイルが変更されると診断情報の更新はスケジュールされましたが、スナップショットの更新はスケジュールされませんでした。そのため、新しい設定エラーは、エディタから別のリクエストが行われてスナップショットが更新されるまで、古い状態のまま残ることがありました。

言語サービスは、追跡対象の設定ファイルへの変更を検出し、デバウンスされたスナップショット更新をスケジュールするようになりました。これにより、エディタからの後続リクエストに依存せず、プッシュされる診断情報が再公開されます。

## 重要である理由

エディタまたは外部ツールが追跡対象の `tsconfig.json` または `jsconfig.json` を変更すると、ネイティブ言語サービスはファイルウォッチャーのイベントだけで、更新された設定エラーを報告できます。回帰テストでは、無効な `target` 値を使用してこの動作を検証します。

## 利用可能性

この変更は、TypeScript 7.0 のリリース後に TypeScript のネイティブコードベースへマージされました。この修正を含む安定版の npm バージョンは出典に記載されていないため、利用する前に、インストール済みバージョンのリリースノートを確認してください。
