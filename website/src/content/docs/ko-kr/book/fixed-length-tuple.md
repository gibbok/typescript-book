고정 길이 튜플은 특정 타입을 가진 요소의 개수를 고정하고, 한 번 정의한 후에는 튜플의 길이를 수정하지 못하게 하는 특정 종류의 튜플입니다.

고정 길이 튜플은 특정 개수의 요소와 특정 타입으로 구성된 값 모음을 나타내야 하며, 튜플의 길이와 타입이 실수로 변경되지 않도록 보장하고자 할 때 유용합니다.

```typescript
const x = [10, 'hello'] as const;
x.push(2); // Error
```
