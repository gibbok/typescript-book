**게시일:** 2026년 7월 27일

TypeScript 유지관리자들은 안정화 릴리스 이후 네이티브 TypeScript 7 도구가 어떻게 통합될지 설명했습니다.

## 변경 사항

Ryan Cavanaugh는 `tsgo` 이름이 사실상 사라진다고 확인했습니다. 프로젝트가 통합된 이슈 백로그로 돌아갈 수 있도록 네이티브 코드베이스를 기본 `microsoft/TypeScript` 저장소로 다시 이전할 예정입니다.

Jake Bailey는 네이티브 VS Code 확장 프로그램을 더 이상 사용하지 않을 계획이 아니라는 점도 분명히 했습니다. 대신 JavaScript 디버거 확장 프로그램과 비슷하게 가까운 시일 내에 번들로 제공될 예정입니다.

개발자에게 이는 별도의 프리뷰 이름과 저장소가 의도된 장기 프로젝트 구조가 아니라 TypeScript 7 마이그레이션의 과도기적 요소임을 의미합니다.
