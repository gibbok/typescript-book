Birleşim Türü, birkaç türden biri olabilen bir değeri temsil eden türdür. Birleşim Türleri, olası her türün arasında `|` simgesi kullanılarak gösterilir.

```typescript
let x: string | number;
x = 'hello'; // Valid
x = 123; // Valid
```
