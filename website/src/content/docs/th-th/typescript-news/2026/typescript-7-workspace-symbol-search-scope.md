**เผยแพร่:** 7 สิงหาคม 2026

Microsoft ได้ merge ขอบเขตการค้นหาสัญลักษณ์ใน workspace สำหรับบริการภาษาแบบเนทีฟของ TypeScript

## สิ่งที่เปลี่ยนแปลง

การตั้งค่า `workspaceSymbols.scope` ใหม่มีสองค่า `allOpenProjects` เป็นค่าเริ่มต้นและค้นหาสัญลักษณ์ในทุกโปรเจกต์ที่เปิดอยู่ ส่วน `currentProject` จำกัดการค้นหาไว้เฉพาะโปรเจกต์ที่มีเอกสารที่ระบุ

ขณะนี้ส่วนขยาย VS Code แบบเนทีฟเพิ่มเอกสาร TypeScript หรือ JavaScript ที่รองรับไปยังคำขอ `workspace/symbol` โดยให้ความสำคัญกับเอกสารที่กำลังใช้งาน และหากไม่มี ก็จะใช้เอกสารที่รองรับซึ่งเปิดอยู่ บริการภาษาจะใช้เอกสารดังกล่าวเฉพาะเมื่อ `workspaceSymbols.scope` เป็น `currentProject` มิฉะนั้นจะยังคงค้นหาในทุกโปรเจกต์ที่เปิดอยู่

## เหตุใดจึงสำคัญ

ใน workspace ที่มีหลายโปรเจกต์และมีสัญลักษณ์ชื่อคล้ายกัน `currentProject` สามารถจำกัดชุดผลลัพธ์ไว้เฉพาะโปรเจกต์ที่เกี่ยวข้อง ค่าเริ่มต้นยังคงพฤติกรรมเดิมไว้ ดังนั้นการเปลี่ยนแปลงนี้จึงเป็นแบบ opt-in

## ความพร้อมใช้งาน

การเปลี่ยนแปลงนี้ถูก merge เข้าสู่ฐานโค้ด TypeScript แบบเนทีฟหลัง TypeScript 7.0 แหล่งข้อมูลไม่ได้ระบุเวอร์ชัน npm แบบเสถียรที่รวมการเปลี่ยนแปลงนี้ ดังนั้นควรตรวจสอบ release notes ของเวอร์ชันที่ติดตั้งก่อนอาศัยการตั้งค่านี้
