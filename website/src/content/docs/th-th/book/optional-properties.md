  label: 13. พร็อพเพอร์ตีที่ไม่บังคับ
---


ออบเจ็กต์สามารถระบุพร็อพเพอร์ตีที่ไม่บังคับได้โดยเติมเครื่องหมายคำถาม `?` ต่อท้ายชื่อพร็อพเพอร์ตี:

```typescript
type X = {
    a: number;
    b?: number; // Optional
};
```

สามารถระบุค่าเริ่มต้นได้เมื่อพร็อพเพอร์ตีเป็นแบบไม่บังคับ:

```typescript
type X = {
    a: number;
    b?: number;
};
const x = ({ a, b = 100 }: X) => a + b;
```
