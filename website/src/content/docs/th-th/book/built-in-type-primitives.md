TypeScript มีชนิดข้อมูลพื้นฐานในตัวหลายชนิดที่สามารถใช้กำหนดตัวแปร พารามิเตอร์ของฟังก์ชัน และชนิดค่าที่ส่งคืน:

* `number`: ใช้แทนค่าตัวเลข รวมถึงจำนวนเต็มและจำนวนจุดทศนิยม
* `string`: ใช้แทนข้อมูลข้อความ
* `boolean`: ใช้แทนค่าตรรกะ ซึ่งเป็นได้ทั้ง true หรือ false
* `null`: ใช้แทนการไม่มีค่า
* `undefined`: ใช้แทนค่าที่ยังไม่ได้กำหนดหรือยังไม่ได้นิยาม
* `symbol`: ใช้แทนตัวระบุที่ไม่ซ้ำกัน โดยทั่วไป Symbol ใช้เป็นคีย์ของพร็อพเพอร์ตีออบเจ็กต์
* `bigint`: ใช้แทนจำนวนเต็มที่มีความแม่นยำไม่จำกัด
* `any`: ใช้แทนชนิดแบบไดนามิกหรือชนิดที่ไม่ทราบ ตัวแปรชนิด any สามารถเก็บค่าชนิดใดก็ได้และจะข้ามการตรวจสอบชนิด
* `void`: ใช้แทนการไม่มีชนิดใด ๆ โดยทั่วไปใช้เป็นชนิดค่าที่ส่งคืนของฟังก์ชันที่ไม่คืนค่า
* `never`: ใช้แทนชนิดของค่าที่ไม่มีวันเกิดขึ้น โดยทั่วไปใช้เป็นชนิดค่าที่ส่งคืนของฟังก์ชันที่โยนข้อผิดพลาดหรือเข้าสู่ลูปไม่รู้จบ
