ชนิด `any` เป็นชนิดพิเศษ (ซูเปอร์ไทป์สากล) ที่สามารถใช้แทนค่าชนิดใดก็ได้ (ค่าพื้นฐาน ออบเจ็กต์ อาร์เรย์ ฟังก์ชัน ข้อผิดพลาด และ symbol) มักใช้ในสถานการณ์ที่ไม่ทราบชนิดของค่าในเวลาคอมไพล์ หรือเมื่อทำงานกับค่าจาก API หรือไลบรารีภายนอกที่ไม่มีการกำหนดชนิดสำหรับ TypeScript

การใช้ชนิด `any` เป็นการบอกคอมไพเลอร์ TypeScript ว่าควรแทนค่าโดยไม่มีข้อจำกัดใด ๆ เพื่อเพิ่มความปลอดภัยด้านชนิดในโค้ดให้สูงสุด ควรพิจารณาสิ่งต่อไปนี้:

* จำกัดการใช้ `any` เฉพาะกรณีที่ไม่ทราบชนิดจริง ๆ
* อย่าส่งคืนชนิด `any` จากฟังก์ชัน เพราะจะลดความปลอดภัยด้านชนิดของโค้ดที่นำไปใช้
* ใช้ `@ts-ignore` แทน `any` หากคุณต้องการปิดข้อผิดพลาดของคอมไพเลอร์

```typescript
let value: any;
value = true; // Valid
value = 7; // Valid
```
