ตัวแปรที่ประกาศด้วย `var`, `let` และ `const` สามารถเพิ่มชนิดแบบไม่บังคับได้:

```typescript
const x: number = 1;
```

TypeScript อนุมานชนิดได้ดี โดยเฉพาะชนิดที่ไม่ซับซ้อน ดังนั้นในกรณีส่วนใหญ่จึงไม่จำเป็นต้องประกาศเช่นนี้

สำหรับฟังก์ชัน สามารถเพิ่มคำกำกับชนิดให้กับพารามิเตอร์ได้:

```typescript
function sum(a: number, b: number) {
    return a + b;
}
```

ตัวอย่างต่อไปนี้ใช้ฟังก์ชันนิรนาม (เรียกอีกอย่างว่าฟังก์ชัน lambda):

```typescript
const sum = (a: number, b: number) => a + b;
```

สามารถละคำกำกับเหล่านี้ได้เมื่อพารามิเตอร์มีค่าเริ่มต้น:

```typescript
const sum = (a = 10, b: number) => a + b;
```

สามารถเพิ่มคำกำกับชนิดค่าที่ส่งคืนให้กับฟังก์ชันได้:

```typescript
const sum = (a = 10, b: number): number => a + b;
```

สิ่งนี้มีประโยชน์อย่างยิ่งสำหรับฟังก์ชันที่ซับซ้อนขึ้น เพราะการเขียนชนิดค่าที่ส่งคืนก่อนลงมืออิมพลีเมนต์ช่วยให้คุณพิจารณาการทำงานของฟังก์ชันได้อย่างรอบคอบ

โดยทั่วไป ควรพิจารณาใส่คำกำกับให้ลายเซ็นชนิด แต่ไม่จำเป็นสำหรับตัวแปรภายในบอดี และควรเพิ่มชนิดให้กับออบเจ็กต์ลิเทอรัลเสมอ
