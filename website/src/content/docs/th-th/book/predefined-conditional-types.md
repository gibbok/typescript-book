ใน TypeScript ชนิดแบบมีเงื่อนไขที่กำหนดไว้ล่วงหน้าคือชนิดแบบมีเงื่อนไขในตัวที่ภาษามีให้ โดยออกแบบมาเพื่อทำการแปลงชนิดที่ใช้กันทั่วไปตามลักษณะของชนิดที่กำหนด

`Exclude<UnionType, ExcludedType>`: ชนิดนี้นำชนิดทั้งหมดจาก Type ที่กำหนดให้กับ ExcludedType ได้ออก

`Extract<Type, Union>`: ชนิดนี้แยกชนิดทั้งหมดจาก Union ที่กำหนดให้กับ Type ได้

`NonNullable<Type>`: ชนิดนี้นำ null และ undefined ออกจาก Type

`ReturnType<Type>`: ชนิดนี้แยกชนิดค่าที่ส่งคืนของฟังก์ชัน Type

`Parameters<Type>`: ชนิดนี้แยกชนิดพารามิเตอร์ของฟังก์ชัน Type

`Required<Type>`: ชนิดนี้ทำให้พร็อพเพอร์ตีทั้งหมดใน Type เป็นแบบบังคับ

`Partial<Type>`: ชนิดนี้ทำให้พร็อพเพอร์ตีทั้งหมดใน Type เป็นแบบไม่บังคับ

`Readonly<Type>`: ชนิดนี้ทำให้พร็อพเพอร์ตีทั้งหมดใน Type เป็นแบบอ่านอย่างเดียว
