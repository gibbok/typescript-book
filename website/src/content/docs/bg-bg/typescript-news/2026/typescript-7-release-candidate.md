**Публикувано:** 18 юни 2026 г.

Microsoft публикува release candidate версията на TypeScript 7.0 като последна предварителна версия преди стабилното издание на TypeScript 7.

## Какво се промени

Release candidate версията премести TypeScript към новия компилатор и езикова услуга, базирани на Go. Логиката за проверка на типовете беше пренесена от TypeScript 6, за да се запази съществуващата семантика и същевременно да се подобри производителността чрез нативен код и паралелизъм със споделена памет.

TypeScript 7 добави паралелна проверка на типовете и компилации с препратки към проекти. Опцията `--checkers` управлява броя на процесите за проверка на типовете, а `--builders` — броя на процесите за компилиране на препратките към проекти.

Към момента на съобщението release candidate версията можеше да бъде инсталирана от npm:

```shell
npm install --save-dev typescript@rc
```

## Съвместимост

Release candidate версията не включваше стабилен програмен API. Екипът на TypeScript предостави пакета за съвместимост `@typescript/typescript6`, за да могат инструментите, които изискват API на TypeScript 6, да работят заедно с новия компилатор.

Release candidate версията също прие настройките по подразбиране на TypeScript 6 и третираше като грешки опциите, които са отбелязани като остарели в TypeScript 6. На екипите беше препоръчано първо да преминат към TypeScript 6, преди да оценят TypeScript 7.
