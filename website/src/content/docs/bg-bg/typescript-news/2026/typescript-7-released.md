**Публикувано:** 8 юли 2026 г.

Microsoft публикува TypeScript 7.0 — първата стабилна версия, изградена върху новата нативна кодова база на проекта, написана на Go.

## Какво се промени

TypeScript 7 използва нативен код, многонишкова обработка със споделена памет и допълнителни оптимизации. Според публикуваните тестове на екипа на TypeScript пълните компилации са били между 7,7 и 11,9 пъти по-бързи от TypeScript 6.

Версията също премества езиковата услуга към Language Server Protocol. Поддържаните редактори могат да използват същата нативна основа за по-бързо зареждане на проекти, диагностика, довършване на код и навигация.

Инсталирайте стабилната версия от npm:

```shell
npm install --save-dev typescript
```

## Съвместимост

TypeScript 7.0 не предоставя стабилен програмен API. Инструментите, които вграждат TypeScript, включително текущите версии на Astro, Vue, MDX, Svelte и някои работни процеси с Angular, може все още да изискват TypeScript 6, докато новият API стане достъпен.

Екипът на TypeScript очаква да въведе новия API в TypeScript 7.1. Преди надграждане проектите трябва да проверят поддръжката от своите рамки и инструменти.
