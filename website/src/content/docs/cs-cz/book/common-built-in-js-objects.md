TypeScript je nadmnožinou JavaScriptu; zahrnuje všechny běžně používané vestavěné objekty JavaScriptu. Rozsáhlý seznam těchto objektů najdete na webu s dokumentací Mozilla Developer Network (MDN):
[https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects)

Zde je seznam některých běžně používaných vestavěných objektů JavaScriptu:

* Function
* Object
* Boolean
* Error
* Number
* BigInt
* Math
* Date
* String
* RegExp
* Array
* Map
* Set
* Promise
* Intl
