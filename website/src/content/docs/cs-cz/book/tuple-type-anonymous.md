Typ n-tice je typ, který představuje pole s pevným počtem prvků a jejich odpovídajícími typy. Typ n-tice vynucuje konkrétní počet prvků a jejich příslušné typy v pevném pořadí. Typy n-tic jsou užitečné, když chcete reprezentovat kolekci hodnot s konkrétními typy, kde má pozice každého prvku v poli určitý význam.

```typescript
type Point = [number, number];
```
