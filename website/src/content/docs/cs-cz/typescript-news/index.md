## Nejnovější zprávy

### [Nativní API TypeScriptu přidává API potřebná pro typescript-eslint](./2026/typescript-native-api-adds-typescript-eslint-apis/)

**Publikováno:** 14. září 2026

Nativní API TypeScriptu přidává API checkeru a typů požadovaná projektem typescript-eslint a zlepšuje kompatibilitu nástrojů.

### [Nativní API TypeScriptu přidává vrstvené virtuální souborové systémy](./2026/typescript-native-api-adds-layered-vfs/)

**Zveřejněno:** 9. září 2026

Nativní API TypeScriptu nyní dokáže aktualizovat snapshoty pomocí dat VFS v paměti nebo ve vrstvách pro přidávání, změny a odstraňování souborů i záložní přístup k hostitelskému systému.

### [TypeScript 7.1 přidává atributy importu do ambientních modulů](./2026/typescript-7-1-import-attributes-ambient-modules/)

**Zveřejněno:** 1. září 2026

Ambientní moduly se vzorem nyní mohou deklarovat typy atributů importu, takže TypeScript může vybírat typové deklarace podle atributů importu.

### [TypeScript 7 opravuje přístupnost setterů v uniích a průnicích](./2026/typescript-7-fixes-setter-accessibility/)

**Zveřejněno:** 24. srpna 2026

Nativní kontrola typů nyní u vlastností unií a průniků respektuje přístupnost setterů odděleně od přístupnosti getterů.

### [TypeScript 7 přidává rozsah vyhledávání symbolů v pracovním prostoru](./2026/typescript-7-workspace-symbol-search-scope/)

**Zveřejněno:** 7. srpna 2026

Nativní jazyková služba přidává nastavení, které dokáže omezit vyhledávání symbolů v pracovním prostoru na aktuální projekt namísto všech otevřených projektů.

### [TypeScript 7 zlepšuje využití paměti funkce Go to Implementation](./2026/typescript-7-go-to-implementation-memory-fix/)

**Zveřejněno:** 30. července 2026

Nativní jazyková služba nyní zabraňuje kvadratickému růstu spotřeby paměti při hledání mnoha implementací ve velkých projektech s hluboce vnořenými typy.

### [TypeScript 7 obnovuje diagnostiku konfigurace po změnách souborů](./2026/typescript-7-refreshes-config-diagnostics/)

**Zveřejněno:** 30. července 2026

Nativní jazyková služba nyní znovu zveřejňuje chyby v souborech `tsconfig.json` a `jsconfig.json` po změně sledovaných konfiguračních souborů.

### [Nativní nástroje TypeScriptu 7 se sjednocují](./2026/typescript-7-native-tooling-consolidates/)

**Zveřejněno:** 27. července 2026

Správci projektu upřesnili, že název `tsgo` se přestává používat, nativní kód se vrátí do hlavního repozitáře TypeScriptu a nativní rozšíření pro VS Code bude součástí distribuce.

### [Nativní API TypeScriptu 7 přidává metody pro generování výstupu](./2026/typescript-7-native-api-adds-emit-methods/)

**Zveřejněno:** 24. července 2026

Nativní API TypeScriptu přidává metody pro generování výstupu do souborového systému a do paměti pro celé programy i vybrané výstupy JavaScriptu nebo deklarací.

### [TypeScript 7.0 je nyní k dispozici](./2026/typescript-7-released/)

**Zveřejněno:** 8. července 2026

TypeScript 7 přináší nový kompilátor a jazykovou službu napsané v Go, s výrazně rychlejšími sestaveními a operacemi v editoru.

### [Oznámen kandidát na vydání TypeScriptu 7.0](./2026/typescript-7-release-candidate/)

**Zveřejněno:** 18. června 2026

Tým TypeScriptu vydal poslední předběžnou verzi TypeScriptu 7, která zahrnuje paralelní kontrolu typů, sestavování projektů a rozšířenou podporu editorů.
