# Tooling native TypeScript 7 sedang dikonsolidasikan


**Diterbitkan:** 27 Juli 2026

Para pengelola TypeScript telah menjelaskan bagaimana tooling TypeScript 7 native akan dikonsolidasikan setelah rilis stabil.

## Perubahan

Ryan Cavanaugh mengonfirmasi bahwa nama `tsgo` pada dasarnya sudah tidak digunakan. Codebase native diperkirakan akan dipindahkan kembali ke repositori utama `microsoft/TypeScript` agar proyek dapat kembali menggunakan backlog issue terpadu.

Jake Bailey juga menjelaskan bahwa ekstensi VS Code native tidak direncanakan untuk dihentikan. Sebaliknya, ekstensi tersebut diperkirakan akan dibundel dalam waktu dekat, serupa dengan ekstensi debugger JavaScript.

Bagi developer, ini berarti nama pratinjau dan repositori terpisah tersebut merupakan bagian transisi dari migrasi TypeScript 7, bukan struktur proyek jangka panjang yang dituju.
