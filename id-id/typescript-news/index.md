# Berita TypeScript


Ikuti rilis penting TypeScript dan pembaruan proyek melalui ringkasan singkat berdasarkan sumber resmi TypeScript.

## Berita terbaru

### [TypeScript 7.1 menambahkan atribut impor ke modul ambient](./2026/typescript-7-1-import-attributes-ambient-modules/)

**Diterbitkan:** 1 September 2026

Modul ambient berpola kini dapat mendeklarasikan tipe atribut impor, sehingga TypeScript dapat memilih tipe berdasarkan atribut pada import.

### [TypeScript 7 memperbaiki aksesibilitas setter pada union dan intersection](./2026/typescript-7-fixes-setter-accessibility/)

**24 Agustus 2026**

Pemeriksa native kini memisahkan aksesibilitas setter dari aksesibilitas getter pada properti union dan intersection.

### [TypeScript 7 menambahkan cakupan pencarian simbol workspace](./2026/typescript-7-workspace-symbol-search-scope/)

**7 Agustus 2026**

Language service native menambahkan pengaturan yang dapat membatasi pencarian simbol workspace ke proyek saat ini.

### [TypeScript 7 memperbaiki penggunaan memori Go to Implementation](./2026/typescript-7-go-to-implementation-memory-fix/)

**30 Juli 2026**

Perbaikan language service native mencegah pertumbuhan memori kuadratik saat menemukan implementasi pada proyek besar dengan tipe yang mendalam.

### [TypeScript 7 menyegarkan diagnosis konfigurasi setelah perubahan berkas](./2026/typescript-7-refreshes-config-diagnostics/)

**30 Juli 2026**

Language service native kini menerbitkan ulang error `tsconfig.json` dan `jsconfig.json` setelah berkas konfigurasi yang dipantau berubah.

### [Tooling native TypeScript 7 sedang dikonsolidasikan](./2026/typescript-7-native-tooling-consolidates/)

**27 Juli 2026**

Para pengelola TypeScript menjelaskan bahwa nama tsgo akan dihentikan, codebase native akan kembali ke repositori utama TypeScript, dan ekstensi VS Code native akan dibundel.

### [API native TypeScript 7 menambahkan metode emit](./2026/typescript-7-native-api-adds-emit-methods/)

**24 Juli 2026**

API TypeScript native menambahkan metode emit ke filesystem dan memori untuk seluruh program serta output JavaScript atau deklarasi yang dipilih.

### [TypeScript 7.0 kini tersedia](./2026/typescript-7-released/)

**8 Juli 2026**

TypeScript 7.0 memperkenalkan compiler dan language service berbasis Go native, dengan peningkatan performa besar untuk build dan editor.
