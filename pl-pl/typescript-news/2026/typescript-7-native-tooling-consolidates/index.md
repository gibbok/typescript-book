# Natywne narzędzia TypeScript 7 są konsolidowane


**Opublikowano:** 27 lipca 2026 r.

Opiekunowie TypeScript wyjaśnili, w jaki sposób natywne narzędzia TypeScript 7 zostaną skonsolidowane po stabilnym wydaniu.

## Co się zmieniło

Ryan Cavanaugh potwierdził, że nazwa `tsgo` w praktyce odchodzi. Natywna baza kodu ma zostać przeniesiona z powrotem do głównego repozytorium `microsoft/TypeScript`, aby projekt mógł ponownie korzystać ze wspólnego rejestru zgłoszeń.

Jake Bailey wyjaśnił również, że wycofanie natywnego rozszerzenia VS Code nie jest planowane. Zamiast tego ma ono zostać w niedalekiej przyszłości dołączone, podobnie jak rozszerzenie debugera JavaScript.

Dla programistów oznacza to, że oddzielne nazwy używane w wersjach zapoznawczych oraz odrębne repozytorium są przejściowymi elementami migracji do TypeScript 7, a nie docelową, długoterminową strukturą projektu.
