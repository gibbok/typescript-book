# ชนิดทูเพิลที่มีชื่อ (มีป้ายกำกับ)



ชนิดทูเพิลสามารถมีป้ายกำกับหรือชื่อแบบไม่บังคับสำหรับสมาชิกแต่ละตัวได้ ป้ายกำกับเหล่านี้ช่วยให้อ่านง่ายและช่วยการทำงานของเครื่องมือ แต่ไม่ส่งผลต่อการดำเนินการที่คุณสามารถทำกับสมาชิกเหล่านั้น

```typescript
type T = string;
type Tuple1 = [T, T];
type Tuple2 = [a: T, b: T];
type Tuple3 = [a: T, T]; // Named Tuple plus Anonymous Tuple
```
