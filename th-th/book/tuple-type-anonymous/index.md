# ชนิดทูเพิล (นิรนาม)



ชนิดทูเพิลคือชนิดที่ใช้แทนอาร์เรย์ซึ่งมีจำนวนสมาชิกคงที่และมีชนิดที่สอดคล้องกัน ชนิดทูเพิลบังคับจำนวนสมาชิกและชนิดของสมาชิกแต่ละตัวตามลำดับที่แน่นอน ชนิดทูเพิลมีประโยชน์เมื่อคุณต้องการแทนคอลเลกชันของค่าที่มีชนิดเฉพาะ โดยตำแหน่งของสมาชิกแต่ละตัวในอาร์เรย์มีความหมายเฉพาะ

```typescript
type Point = [number, number];
```
