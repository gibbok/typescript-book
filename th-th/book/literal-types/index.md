# ชนิดลิเทอรัล



ชนิดลิเทอรัลคือเซตที่มีสมาชิกเพียงหนึ่งค่าอยู่ภายในชนิดแบบกลุ่ม โดยกำหนดค่าที่เฉพาะเจาะจงอย่างยิ่งซึ่งเป็นค่าพื้นฐานของ JavaScript

ชนิดลิเทอรัลใน TypeScript ได้แก่ ตัวเลข สตริง และบูลีน

ตัวอย่างลิเทอรัล:

```typescript
const a = 'a'; // String literal type
const b = 1; // Numeric literal type
const c = true; // Boolean literal type
```

ชนิดลิเทอรัลแบบสตริง ตัวเลข และบูลีนถูกใช้ในยูเนียน ตัวป้องกันชนิด และนามแฝงชนิด
ในตัวอย่างต่อไปนี้ คุณจะเห็นนามแฝงชนิดยูเนียน โดย `O` ประกอบด้วยค่าที่ระบุไว้เท่านั้น และสตริงอื่นไม่ถือว่าถูกต้อง:

```typescript
type O = 'a' | 'b' | 'c';
```
