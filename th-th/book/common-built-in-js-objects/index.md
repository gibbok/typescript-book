# ออบเจ็กต์ JS ในตัวที่ใช้ทั่วไป



TypeScript เป็นซูเปอร์เซตของ JavaScript จึงมีออบเจ็กต์ JavaScript ในตัวที่ใช้กันทั่วไปทั้งหมด คุณสามารถดูรายการออบเจ็กต์เหล่านี้อย่างละเอียดได้ในเว็บไซต์เอกสาร Mozilla Developer Network (MDN):
[https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects)

ต่อไปนี้คือรายการออบเจ็กต์ JavaScript ในตัวที่ใช้กันทั่วไปบางส่วน:

* Function
* Object
* Boolean
* Error
* Number
* BigInt
* Math
* Date
* String
* RegExp
* Array
* Map
* Set
* Promise
* Intl
