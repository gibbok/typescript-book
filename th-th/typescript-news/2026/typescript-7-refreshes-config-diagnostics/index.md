# TypeScript 7 รีเฟรช diagnostics ของการกำหนดค่าหลังไฟล์เปลี่ยนแปลง


**เผยแพร่:** 30 กรกฎาคม 2026

Microsoft ได้ merge การแก้ไขที่รีเฟรช diagnostics ของไฟล์การกำหนดค่าในบริการภาษาแบบเนทีฟของ TypeScript หลังไฟล์ `tsconfig.json` หรือ `jsconfig.json` ที่ติดตามอยู่มีการเปลี่ยนแปลง

## สิ่งที่เปลี่ยนแปลง

diagnostics ของไฟล์การกำหนดค่าจะถูกเผยแพร่ระหว่างการอัปเดต snapshot ของบริการภาษา ก่อนหน้านี้ การเปลี่ยนแปลงไฟล์การกำหนดค่าที่เฝ้าดูจะกำหนดเวลาให้รีเฟรช diagnostics แต่ไม่ได้กำหนดเวลาให้อัปเดต snapshot ดังนั้นข้อผิดพลาดการกำหนดค่าใหม่อาจยังแสดงข้อมูลเก่าจนกว่า editor จะส่งคำขออื่นที่อัปเดต snapshot

ขณะนี้บริการภาษาตรวจพบการเปลี่ยนแปลงในไฟล์การกำหนดค่าที่ติดตาม และกำหนดเวลาการอัปเดต snapshot แบบ debounced ซึ่งทำให้ pushed diagnostics ถูกเผยแพร่อีกครั้งโดยไม่ต้องพึ่งคำขอติดตามผลจาก editor

## เหตุใดจึงสำคัญ

เมื่อ editor หรือเครื่องมือภายนอกเปลี่ยนไฟล์ `tsconfig.json` หรือ `jsconfig.json` ที่ติดตามอยู่ บริการภาษาแบบเนทีฟสามารถรายงานข้อผิดพลาดการกำหนดค่าที่อัปเดตแล้วจากเหตุการณ์ file-watcher เพียงอย่างเดียว regression test ตรวจสอบพฤติกรรมนี้ด้วยค่า `target` ที่ไม่ถูกต้อง

## ความพร้อมใช้งาน

การเปลี่ยนแปลงนี้ถูก merge เข้าสู่ฐานโค้ด TypeScript แบบเนทีฟหลังการเผยแพร่ TypeScript 7.0 แหล่งข้อมูลไม่ได้ระบุเวอร์ชัน npm แบบเสถียรที่รวมการเปลี่ยนแปลงนี้ ดังนั้นควรตรวจสอบ release notes ของเวอร์ชันที่ติดตั้งก่อนอาศัยการแก้ไขนี้
