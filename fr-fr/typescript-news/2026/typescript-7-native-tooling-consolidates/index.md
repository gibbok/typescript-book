# L'outillage natif de TypeScript 7 est en cours de consolidation


**Publié le :** 27 juillet 2026

Les mainteneurs de TypeScript ont précisé comment l'outillage natif de TypeScript 7 serait consolidé après la version stable.

## Ce qui a changé

Ryan Cavanaugh a confirmé que le nom `tsgo` avait effectivement disparu. La base de code native devrait revenir dans le dépôt principal `microsoft/TypeScript` afin que le projet puisse retrouver une liste unifiée de problèmes à traiter.

Jake Bailey a également précisé qu'il n'était pas prévu de déprécier l'extension native pour VS Code. Elle devrait au contraire être intégrée prochainement, à l'image de l'extension de débogage JavaScript.

Pour les développeurs, cela signifie que les noms de préversion et le dépôt séparé constituent des éléments transitoires de la migration vers TypeScript 7 et non la structure à long terme prévue pour le projet.
