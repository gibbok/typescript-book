# Tuple ثابت الطول



Tuple ثابت الطول هو نوع محدد من Tuple يفرض عددًا ثابتًا من العناصر ذات أنواع محددة، ولا يسمح بأي تعديلات على طول Tuple بعد تعريفه.

تفيد أنواع Tuple ثابتة الطول عندما تحتاج إلى تمثيل مجموعة من القيم بعدد محدد من العناصر وأنواع محددة، وتريد ضمان عدم تغيير طول Tuple وأنواعه من دون قصد.

<!-- skip -->
```typescript
const x = [10, 'hello'] as const;
x.push(2); // Error
```
