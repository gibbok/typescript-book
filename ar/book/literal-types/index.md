# الأنواع الحرفية



النوع الحرفي هو مجموعة أحادية العنصر داخل نوع جماعي؛ فهو يعرّف قيمة دقيقة جدًا تكون قيمة بدائية في JavaScript.

الأنواع الحرفية في TypeScript هي الأعداد والسلاسل النصية والقيم المنطقية.

مثال على القيم الحرفية:

```typescript
const a = 'a'; // نوع سلسلة نصية حرفية
const b = 1; // نوع قيمة عددية حرفية
const c = true; // نوع قيمة منطقية حرفية
```

تُستخدم الأنواع الحرفية النصية والعددية والمنطقية في الاتحادات وحراس الأنواع والأسماء المستعارة للأنواع.
في المثال الآتي، يمكنك رؤية اسم مستعار لنوع اتحاد. يتكون `O` من القيم المحددة فقط، ولا تكون أي سلسلة نصية أخرى صالحة:

```typescript
type O = 'a' | 'b' | 'c';
```
