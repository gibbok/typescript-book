# نوع Tuple (مجهول الاسم)



نوع Tuple هو نوع يمثّل مصفوفة ذات عدد ثابت من العناصر وأنواعها المقابلة. يفرض نوع Tuple عددًا محددًا من العناصر وأنواعًا محددة لكل منها بترتيب ثابت. تفيد أنواع Tuple عندما تريد تمثيل مجموعة من القيم ذات أنواع محددة، بحيث يكون لموضع كل عنصر في المصفوفة معنى محدد.

```typescript
type Point = [number, number];
```
