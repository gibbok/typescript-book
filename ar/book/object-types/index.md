# أنواع الكائنات



في TypeScript، تصف أنواع الكائنات شكل الكائن. فهي تحدد أسماء خصائص الكائن وأنواعها، وما إذا كانت تلك الخصائص مطلوبة أم اختيارية.

في TypeScript، يمكنك تعريف أنواع الكائنات بطريقتين أساسيتين:

تعرّف الواجهة شكل الكائن بتحديد أسماء خصائصه وأنواعها وما إذا كانت اختيارية.

```typescript
interface User {
    name: string;
    age: number;
    email?: string;
}
```

يعرّف الاسم المستعار للنوع، على غرار الواجهة، شكل الكائن. لكنه يستطيع أيضًا إنشاء نوع مخصّص جديد يستند إلى نوع موجود أو إلى مجموعة من الأنواع الموجودة. ويشمل ذلك تعريف أنواع الاتحاد وأنواع التقاطع وأنواع معقدة أخرى.

```typescript
type Point = {
    x: number;
    y: number;
};
```

يمكن أيضًا تعريف نوع بصورة مجهولة:

```typescript
const sum = (x: { a: number; b: number }) => x.a + x.b;
console.log(sum({ a: 5, b: 1 }));
```
