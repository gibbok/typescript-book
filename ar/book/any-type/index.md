# النوع Any



النوع `any` هو نوع خاص (نوع فائق عام) يمكن استخدامه لتمثيل أي نوع من القيم (الأنواع الأولية، والكائنات، والمصفوفات، والدوال، والأخطاء، والرموز). وغالبًا ما يُستخدم في الحالات التي لا يكون فيها نوع القيمة معروفًا في وقت التصريف، أو عند التعامل مع قيم من واجهات برمجة تطبيقات أو مكتبات خارجية لا تحتوي على تعريفات أنواع TypeScript.

باستخدام النوع `any`، فإنك تُعلم مصرّف TypeScript بأن القيم يجب أن تُمثّل من دون أي قيود. لتحقيق أقصى قدر من أمان الأنواع في شيفرتك، ضع ما يلي في الحسبان:

* احصر استخدام `any` في الحالات المحددة التي يكون فيها النوع مجهولًا بالفعل.
* لا تُعِد أنواع `any` من دالة، لأن ذلك يُضعف أمان الأنواع في الشيفرة التي تستخدمها.
* بدلًا من `any`، استخدم `@ts-ignore` إذا كنت بحاجة إلى إسكات المصرّف.

```typescript
let value: any;
value = true; // Valid
value = 7; // Valid
```
