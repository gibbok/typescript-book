# كائنات JS المضمّنة الشائعة



TypeScript هو مجموعة فائقة من JavaScript؛ ويشمل جميع كائنات JavaScript المضمّنة شائعة الاستخدام. يمكنك العثور على قائمة موسّعة بهذه الكائنات في موقع توثيق شبكة مطوري Mozilla (MDN):
[https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects)

فيما يلي قائمة ببعض كائنات JavaScript المضمّنة شائعة الاستخدام:

* Function
* Object
* Boolean
* Error
* Number
* BigInt
* Math
* Date
* String
* RegExp
* Array
* Map
* Set
* Promise
* Intl
