# التعليقات التوضيحية للأنواع



يمكن اختياريًا إضافة نوع إلى المتغيرات المصرّح بها باستخدام `var` و`let` و`const`:

```typescript
const x: number = 1;
```

يجيد TypeScript استدلال الأنواع، ولا سيما الأنواع البسيطة، لذلك لا تكون هذه التصريحات ضرورية في معظم الحالات.

يمكن إضافة تعليقات توضيحية للأنواع إلى معاملات الدوال:

```typescript
function sum(a: number, b: number) {
    return a + b;
}
```

فيما يأتي مثال يستخدم دالة مجهولة (تُسمّى أيضًا دالة لامبدا):

```typescript
const sum = (a: number, b: number) => a + b;
```

يمكن الاستغناء عن هذه التعليقات التوضيحية عند وجود قيمة افتراضية للمعامل:

```typescript
const sum = (a = 10, b: number) => a + b;
```

يمكن إضافة تعليقات توضيحية لنوع الإرجاع إلى الدوال:

```typescript
const sum = (a = 10, b: number): number => a + b;
```

يفيد هذا خصوصًا مع الدوال الأكثر تعقيدًا، إذ يمكن أن تساعدك كتابة نوع الإرجاع قبل التنفيذ على التفكير مليًا في الدالة.

بوجه عام، فكّر في إضافة تعليقات توضيحية إلى تواقيع الأنواع، لا إلى المتغيرات المحلية داخل المتن، وأضف دائمًا أنواعًا إلى الكائنات الحرفية.
