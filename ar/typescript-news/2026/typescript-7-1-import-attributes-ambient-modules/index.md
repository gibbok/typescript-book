# TypeScript 7.1 يضيف سمات الاستيراد إلى الوحدات المحيطية


**تاريخ النشر:** 1 سبتمبر 2026

يدعم المترجم الأصلي في TypeScript الآن أنواع سمات الاستيراد في تصريحات الوحدات المحيطية ذات الأنماط. وبذلك يمكن للتصريحات التمييز بين عمليات import باستخدام سمات مثل `type: 'css'` أو `type: 'text'`.

## ما الذي تغيّر

عندما تحتوي عملية import على سمات، يمكن لـ TypeScript حلها إلى وحدة محيطية ذات نمط مطابق. تعتمد المطابقة على قابلية الإسناد، وإذا تطابقت عدة تصريحات يختار TypeScript التصريح ذي نوع السمات الأكثر تحديدًا.

في الوقت الحالي تقتصر أنواع السمات في هذه التصريحات على الخصائص العادية التي تكون قيمها من أنواع السلاسل الحرفية. يمكن دمج التصريحات ذات النمط نفسه وأنواع السمات المتطابقة، بينما تظل الأنواع المختلفة منفصلة.

## التوافق

دُمج التغيير ضمن milestone الخاص بـ TypeScript 7.1.0 Beta. ولا يضيف تصريحات مضمّنة لاستيراد CSS أو النصوص إلى المكتبة القياسية، لذلك ما زالت المشاريع والأدوات بحاجة إلى تعريف الوحدات المحيطية المطلوبة.
