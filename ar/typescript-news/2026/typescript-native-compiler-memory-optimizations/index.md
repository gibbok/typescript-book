# مترجم TypeScript الأصلي يقلّل استهلاك الذاكرة بتحسينات فاحص الأنواع


**تاريخ النشر:** 14 أكتوبر 2026

دمجت Microsoft عدة تحسينات للذاكرة في مترجم TypeScript الأصلي. تقلّل هذه التغييرات الذاكرة التي تحتفظ بها هياكل البيانات الداخلية لفاحص الأنواع دون تغيير صياغة TypeScript.

## ما الذي تغيّر

* أصبحت كتل ساحات الذاكرة ذات الأنواع تستهدف نحو 512 بايت بدلًا من عدد ثابت يبلغ 256 كائنًا. في اختبار VS Code لهذا التغيير، انخفضت ذاكرة heap المحتفظ بها بنسبة 8.54% ومسح جامع القمامة بنسبة 10.44%، بينما زادت عمليات التخصيص بنسبة 13.91%.
* نُقلت التواقيع الاختيارية ومعلومات الفهارس وذاكرات التخزين المؤقت لباني العقد خارج سجلات `StructuredType`، فانخفض حجمها من 144 إلى 88 بايت.
* تستخدم عقد الأنواع المحلّلة والتواقيع مخازن روابط عقد مقسّمة إلى صفحات عند توفر معرّفات عقد ثابتة، مع الرجوع إلى خريطة للمعرّفات الأخرى.

## التوفّر

دُمجت هذه التغييرات في 14 أكتوبر 2026. لا تحدد طلبات السحب الأصلية إصدار npm مستقرًا يتضمنها. تقتصر نتائج الاختبار على التغيير وعبء العمل اللذين جرى قياسهما.
