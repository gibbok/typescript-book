# Las herramientas nativas de TypeScript 7 se están consolidando


**Publicado:** 27 de julio de 2026

Los mantenedores de TypeScript han aclarado cómo se consolidarán las herramientas nativas de TypeScript 7 después de la versión estable.

## Qué cambió

Ryan Cavanaugh confirmó que el nombre `tsgo` está desapareciendo de forma efectiva. Se espera que el código nativo vuelva al repositorio principal `microsoft/TypeScript`, de modo que el proyecto pueda volver a tener un único backlog de incidencias.

Jake Bailey también aclaró que no está previsto retirar la extensión nativa de VS Code. En su lugar, se espera que se integre próximamente, de forma similar a la extensión del depurador de JavaScript.

Para quienes desarrollan con TypeScript, esto significa que los nombres y el repositorio separados usados durante la vista previa son elementos transitorios de la migración a TypeScript 7, no la estructura prevista a largo plazo.
